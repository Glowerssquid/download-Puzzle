Готовый статический сайт для скачивания приложения для поиска пазлов.

Разработчик: Будусов Захар Васильевич.

Описание:
Сайт предназначен для простой загрузки приложения, которое помогает пользователю искать пазлы. На странице размещена краткая информация о приложении и две ссылки для скачивания:
- Android-версия в формате APK;
- Windows-версия в архиве RAR.

Как использовать:
1. Загрузите все содержимое этой папки на хостинг: index.html, styles.css, script.js и папку download.
2. Откройте index.html через домен или HTTPS-ссылку.
3. QR-код для APK создается автоматически на основе текущего адреса сайта.
4. Пользователь выбирает нужную версию приложения и скачивает файл.

Важно:
- При открытии сайта напрямую с компьютера через file:// QR-код может вести на локальный путь. Для корректной работы разместите сайт на хостинге.
- APK: download/app-debug.apk — Android-версия приложения для поиска пазлов.
- Desktop архив: download/PuzzlesWinFormsExact_2.rar — Windows-версия приложения для поиска пазлов.
